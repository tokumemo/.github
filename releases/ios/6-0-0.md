# v6.0.0
2026年05月06日(水)

## Overview
UIKit で実現できる機能はすべて SwiftUI でも実装可能であったため、コードの可読性・保守性向上を目的に SwiftUI へ全面移行しました。
合わせて iOS 26 で導入された Liquid Glass デザインへの対応も行っています。

## Changes

### New Features
- manaba のスマホ用表示とPC用表示の切り替え機能を詳細設定画面に追加

### Improvements & Bug Fixes
- 各画面の Liquid Glass 化
    - 一部画面では対応できていない
- アプリ内リンクを新しいものに変更
    - 図書館のリンクを新しいものに差し替え
    - 公式サイトを新しいものに差し替え
- 画像をフォトに保存できない問題を解決
- クレジットをiPhoneの設定に表示させる

### Breaking Changes
- cアカウントの情報がリセットされるので再ログインが必要
