## About us

大学の講義情報、レポート提出の期限、図書館の開館時間などの重要な情報を集約し、異なるWebサイトやシステムを複数使う手間を省きます。

自分のアカウントとパスワードを保存していれば、即座にアクセスできます。アカウントとパスワードはデバイスに保存されており外部に公開されないため、セキュリティ的にも安心です。

アプリは完全無料で利用できます。不快な広告や不適切な広告も表示されず、快適に利用できます。
